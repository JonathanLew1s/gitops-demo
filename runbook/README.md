# Session runbook

Each chapter file has scenes shaped as:

- **Say**: talk track
- **Do**: what the assistant runs, on cue
- **See**: what should visibly change on the site
- **Check**: an assertion before moving on
- **Plan B**: fallback if the live path misbehaves

Chapters are added as they are built and rehearsed. Site: https://demo.instagib.co.uk
