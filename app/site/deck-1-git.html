Part 1 · Git

What is Git?

A tool that remembers every version of your files: what changed, who changed it, when, and why.

firewall.rules
allow web-01 → db-01 port 5432
allow web-01 → cache-01 port 6379
allow web-01 → cache-01 port 6380
allow web-02 → db-01 port 5432

The label on that change

Who: an engineer
When: Tuesday, 14:02
Why: "Open DB access for the new web server; move cache off the old port"

Written by the person making the change, kept with it forever.

Snapshots, not surveillance

Git doesn't watch you type. You choose when to save a snapshot (a commit).

Differences on demand

It compares two snapshots and shows exactly what changed, line by line. Red out, green in.

Nothing is lost

Every earlier snapshot is still there. Go back to how it was last Tuesday in seconds.

In the VM worldWord's "Track Changes", but for any file, the whole folder, kept forever, and impossible to quietly rewrite.
SAY: forget the jargon for a minute. Git is "Track Changes" for a whole folder. You decide when to take a snapshot; Git can then show you the difference between any two. Press → once: the red and green lines are the change. Press again: the label (who, when, why) travels with it. Press again: the three ideas to remember. Part 1 · Git

A commit is a snapshot with a name tag

Each commit stores

  • the snapshot of the files
  • author, time, message
  • the hash of its parent

Why security cares

The hash covers the parent's hash, so history cannot be quietly edited. Change one old commit and every hash after it changes.

In the VM worldA spreadsheet saved as rules_v7.xlsx, but every version kept, labelled, and impossible to quietly alter.
SAY: the 7-character codes under each dot are the hash. Real ones are longer, these are illustrative. Press → to build the chain commit by commit.

Part 1 · Git · LIVE

Your first commit, for real

$ git init demo && cd demo # a new, empty history
$ echo "hello" > notes.txt && git status # git sees an untracked file
$ git add notes.txt && git commit -m "first note" # snapshot saved
$ git log --oneline --graph # the history, with hashes
$ git diff HEAD~1 # exactly what changed, and who did it

Watch the terminal. This is a throwaway sandbox, not the demo site.

A second checkout of the platform repo, so a platform fix never mixes with other work in progress.

Cheat sheet

CommandPlain English
git statusWhat has changed since the last commit?
git add / git commitChoose edits, then save them as a named snapshot
git branch / git switchStart or move between safe drafts
git push / git pullShare my work / get everyone else's
git log / git diffThe history, and exactly what changed
git revertUndo a change by adding a new one
